# ПлюсУгол

Приложение для Android для мастеров натяжных потолков. В нём весь путь заказа — от замера на объекте
до монтажа и оплаты.

- **Замер и чертёж.** Эскиз тапами по углам, ввод стен и диагоналей, точный чертёж в масштабе, вырезы
  и дополнительные формы, швы по ширине рулона.
- **Смета.** Работы и материалы из своей номенклатуры, скидки, источники клиентов с наценкой, PDF
  для заказчика.
- **Договор.** Шаблон с подстановками, особые условия для заказчика, PDF.
- **Для цеха и монтажника.** PDF для цеха с размерами и диагоналями; наряд монтажнику без цен.
- **Заказы.** Этапы «Замер — Согласование — Договор — Архив», календарь замеров и монтажей, оплаты
  и долги, итоги месяца.
- **Работает без интернета.** Заказы хранятся на телефоне. Обмен между телефонами (своими и
  сотрудников) идёт через ваш Яндекс Диск — [как подключить](guide/sync.md).

## Как установить

1. Откройте [последний выпуск](../../releases/latest) и скачайте файл `.apk`.
2. Откройте его на телефоне. Если Android спросит, разрешите установку из этого источника.
3. Чтобы обновиться, скачайте новый `.apk` и установите поверх. Заказы сохранятся.

## Обмен между телефонами

Как подключить обмен заказами через Яндекс Диск — себе и сотрудникам, со снимками экранов:
[инструкция](guide/sync.md).

## Лицензия

Первые 14 дней бесплатно, с входом через Яндекс и без него. Чтобы продлить, напишите разработчику
и сообщите свой ID из «Настройки → Аккаунт».
